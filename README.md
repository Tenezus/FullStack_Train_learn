# Html_CSS_FullStack_Train

## Objectif du défi

Ce défi a pour but d’encourager chaque développeur à apprendre, innover et construire un projet complet en combinant plusieurs technologies.  
Les langages de base comme **HTML et CSS** sont bien entendu utilisés dans la plupart des projets, mais **ils ne sont pas obligatoires**.  
Tu dois surtout **choisir deux langages ou frameworks** principaux avec lesquels tu vas bâtir ton projet.

L’objectif est simple : tu choisis tes technologies, tu construis ton application, et tu documentes **chaque étape de ton apprentissage et de ton processus de création**.

---

## Règles du défi

- Tu choisis **deux langages ou frameworks principaux** pour réaliser ton projet (ex : React, PHP, Flutter, Django, etc.).
- Tu dois livrer **4 fichiers clés** :
  1. Le frontend (interface utilisateur)
  2. Le backend (si ton projet en a un)
  3. Un fichier README complet
  4. Une documentation ou des captures d’écran montrant ton projet en action
- Le nom de ton projet doit suivre ce format :
  - Le nom du framework principal (ex : `flutter`)
  - Suivi des **deux premières lettres de ton prénom**
  - Exemple : `flutter_jo` si tu t’appelles Jonas

---

## Ce que tu dois faire

1. **Documenter ton apprentissage** étape par étape pour chaque technologie choisie.
2. **Rédiger un README clair** contenant :
   - Les langages/frameworks utilisés
   - Les raisons de ton choix
   - Comment tu as appris à les utiliser
   - Ton plan de réalisation
   - Comment exécuter ton application
3. **Soigner la rédaction** du README pour qu’il soit clair, lisible et structuré comme un vrai projet pro ou open-source.
4. **Faire preuve de créativité** et proposer une solution personnelle.

---

## Objectif final

Ce défi est un **projet communautaire** qui a pour but de :

- Te faire progresser techniquement
- T’habituer à structurer un projet de manière professionnelle
- T’obliger à documenter ton code et ton processus
- T’encourager à aller au bout d’un projet ambitieux

---

## Informations importantes

- Le README est essentiel : il doit expliquer clairement ta démarche, les outils utilisés, et comment ton projet fonctionne.
- Tu peux inclure des captures d’écran ou des vidéos pour illustrer ton travail.
- Le défi peut être réalisé seul ou en groupe.
- Ce n’est pas la perfection qui compte, mais ta **capacité à apprendre, tester, construire et finaliser** ton projet.

---

## Exemples de combinaisons possibles

- React + Node.js  
- Flutter + Laravel  
- PHP + MySQL  
- JavaScript + Express.js  
- Angular + Firebase  
- Python (Flask ou Django) + PostgreSQL
